# MintPDF 🍃

**A Professional, Privacy-First PDF Utility Tool.**

MintPDF is a powerful Flutter application designed to handle all your PDF manipulation needs directly on your device. Built with a focus on privacy, speed, and a modern user experience, MintPDF ensures your sensitive documents never leave your phone.

---

## ✨ Features

*   **📸 Images to PDF**: Seamlessly convert multiple photos or scans into a single, high-quality PDF document.
*   **🗜️ Compress PDF**: Optimize your PDF files to reduce size without compromising readability, making them easier to share.
*   **🔗 Merge PDFs**: Combine multiple PDF documents into one organized file.
*   **✂️ Split PDF**: Extract specific pages or split a large document into separate files.
*   **🛡️ 100% On-Device Processing**: No cloud uploads. No servers. Your data stays with you.
*   **🎨 Modern UI**: A clean, "Fresh Workspace" aesthetic with dark mode support.

---

## 🛠️ Tech Stack

MintPDF is built with the latest Flutter technologies to ensure performance and maintainability.

*   **Framework**: [Flutter](https://flutter.dev)
*   **State Management**: [Riverpod](https://riverpod.dev)
*   **PDF Engine**: [Syncfusion Flutter PDF](https://pub.dev/packages/syncfusion_flutter_pdf)
*   **File Handling**: `file_picker`, `path_provider`, `open_file`
*   **UI Components**: `google_fonts`, `reorderable_grid_view`
